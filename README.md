# dsh-test

This Superagent test repository is a minimal Node.js starter using pnpm. It uses JavaScript ES modules and Node's built-in test runner, with no third-party dependencies.

## Getting started

Install Node.js 24 or newer and [pnpm](https://pnpm.io/installation) 11.7.0 (the version pinned in `package.json`).

From the repository root:

```sh
pnpm install --frozen-lockfile
pnpm start
pnpm test
```

`pnpm start` prints `Hello, world!`. To use this starter for your own project, rename the package in `package.json`, replace the sample code in `src/`, and put your tests in `test/`.
